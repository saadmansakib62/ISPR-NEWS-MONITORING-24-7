# ISPR News Monitoring System

24/7 Live Electronic & Print Media Harvester and Multi-Sector Intelligence Report Generator.

## Live Deployment
- **GitHub Pages:** Ensure `index.html` is in the root of the `main` branch and enable **Settings -> Pages -> Deploy from branch (`main` / `root`)**.
- **Netlify Domain:** `https://isprbdnewsreport.netlify.app/`

## Files Included
- `index.html` — Complete self-contained single-file web application
- `manifest.json` — Progressive Web App (PWA) manifest for desktop & mobile installation
- `.nojekyll` — Bypasses Jekyll processing on GitHub Pages for instant static deployment
